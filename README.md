<h1 align="center">🛩️ Flie: Proyecto para Desarrollo Libre - SeneSoft</h1>

<h2>📋 Descripción</h2>
<p>
  Este proyecto es una <strong>pagina web</strong> creada con React JS y Laravel, cuya funcion principal es reservar y gestionar vuelos.
</p>

<h2>⚙️ Tecnologías Utilizadas</h2>
<ul>
  <li>CSS3</li>
  <li>React js</li>
  <li>Laravel</li>
  <li>MySQL</li>
</ul>

<h1>¡Ejecuta el proyecto tu mismo!</h1>
<h2>Clona el proyecto:</h2>
<pre><code>git clone https://github.com/SaraCuellar89/SenaSoft_Desarrollo_Libre.git</code></pre>

<h2>Ejecuta el servidor:</h2>
<p>Descarga las dependencias necesarias:</p>
<pre><code>composer install</code></pre>
<p>Carga las migraciones:</p>
<pre><code>php artisan migrate</code></pre>
<p>Carga los seeders:</p>
<pre><code>php artisan db:seed</code></pre>
<p>Corre el servidor:</p>
<pre><code>php artisan serve</code></pre>

<h2>Ejecuta el front:</h2>
<p>Descarga las dependencias necesarias:</p>
<pre><code>npm install</code></pre>
<p>Ejecuta:</p>
<pre><code>npm run dev</code></pre>
<p>Ve a: http://localhost:5173/</p>
